FeliVet Insight – Important Points for a Paper

1. Project Overview
FeliVet Insight is a mobile-based feline health triage support system designed to assist cat owners and veterinary users in identifying possible skin-related diseases and prioritizing whether urgent veterinary attention is needed. The system combines image analysis, symptom input, and rule-based reasoning to provide a practical preliminary assessment rather than a final diagnosis.

2. Main Purpose of the System
The system aims to help users detect possible skin conditions in cats by analyzing a photo of the affected area and combining that with systemic symptoms such as vomiting, lethargy, and loss of appetite. It is especially useful for early screening, symptom tracking, and deciding whether the case should be considered urgent.

3. How the Triage System Works
The triage process is based on a multi-step workflow:
- Step 1: The user uploads or captures a photo of the cat’s affected area.
- Step 2: The user can also select systemic symptoms from a checklist, such as vomiting, lethargy, or loss of appetite.
- Step 3: The user can type a free-form description of what they noticed, which is processed by the symptom-intake component.
- Step 4: The image is analyzed using a machine learning model loaded from a TensorFlow Lite file.
- Step 5: The system extracts visual evidence from the image and combines it with the user-provided symptoms.
- Step 6: An expert system evaluates the combination of visual findings and symptoms to produce a triage result.

This means the app does not rely on the image alone. It uses both visual evidence and clinical symptom context to make a more informed assessment.

4. Role of the AI and Symptom Intake Module
The AI component is used as a symptom-intake assistant rather than as an autonomous medical diagnostician. Its task is to interpret the user’s natural language description and convert it into a structured symptom checklist. This is important because it makes the system more user-friendly while keeping the medical reasoning conservative and controlled.

The system uses a structured approach to avoid overclaiming. If the user’s text is unclear, incomplete, or ambiguous, the app uses a conservative fallback strategy instead of inventing symptoms or making unsupported claims.

5. How Urgency Is Defined
Urgency in this system is not based on a single factor. It is determined by combining several indicators:
- Visual confidence: how strongly the image model detects a supported disease class.
- Number of systemic symptoms reported: symptoms like vomiting, lethargy, and appetite loss increase urgency.
- Disease risk level: some diseases are more serious than others and therefore receive a higher urgency rating.
- Ambiguity of the result: if the model’s detection is uncertain or conflicting, the system may increase caution.
- Presence of multiple symptoms together: when several symptoms are reported at once, the case is treated as more urgent.

In practical terms, the system classifies cases into urgency levels such as stable, moderate, or high. Cases with strong visual evidence, multiple systemic symptoms, or high-risk conditions are flagged as more urgent. The system also recommends veterinary care even when visual evidence is weak, because the absence of visual evidence does not rule out illness.

6. Why the System Is Conservative
One important design principle is that the system is conservative. It does not claim to make a definitive diagnosis. Instead, it provides a triage-style recommendation that encourages veterinary evaluation when needed. This is especially important because skin conditions can have overlapping symptoms, and some underlying diseases may not be visible in the image alone.

7. Technical Stack and Technologies Used
The project is developed using Flutter and Dart for the mobile application interface.
Important technologies include:
- Flutter: cross-platform mobile app framework.
- Dart: primary programming language used to build the app logic and UI.
- TensorFlow Lite / Flutter Vision: used for image-based disease detection.
- image_picker: allows the user to take a photo from camera or gallery.
- Flutter Secure Storage: used to store AI settings, API keys, and model-related configuration.
- HTTP and path_provider: used for network access and local model file management.
- Asset files: the app uses local model and label files such as CatDisease.tflite and labels.txt.
- AI provider support: the system supports both local and cloud-based AI inference options.

8. Why Flutter and Dart Are Suitable
Flutter and Dart are suitable because they allow rapid development of a polished mobile app for both Android and iOS. Dart provides a clean object-oriented structure for managing state, UI, and application logic. Flutter also offers a fast development cycle and good support for modern mobile interfaces.

9. Important Academic/Research Points to Mention
Possible points to include in a paper or report:
- The system combines computer vision with rule-based medical triage logic.
- It uses both image evidence and symptom history for decision support.
- It focuses on early screening rather than final diagnosis.
- It adopts a conservative approach to avoid overconfidence and false medical claims.
- It supports human-centered interaction by allowing users to describe symptoms in natural language.
- It demonstrates how AI can be applied in veterinary support systems.

10. Suggested Paper Summary Sentence
This project presents a mobile-based feline triage support system that integrates image analysis, symptom intake, and rule-based urgency assessment to help users identify possible skin-related diseases and determine when veterinary attention is needed.

11. Short Conclusion
The app is valuable because it combines technological innovation with practical veterinary decision support. Its main contribution lies in merging visual detection, symptom interpretation, and urgency evaluation into a single user-friendly system that can guide users toward safer and more timely care.
